# PRD: 급할 때 약국 찾기 (가칭)

> 버전 0.1 / 2026-10-09 / 상태: 초안
> `[결정 필요]` 표시는 사용자 확정이 필요한 항목입니다. 현재는 괄호 안의 기본값으로 가정합니다.

## 1. 한 줄 요약
상비약이 급할 때 **지금 문 연 가까운 약국**을 찾고, **전화로 확인**한 뒤, **주차 정보와 길 안내**까지 한 번에 받는 웹/안드로이드 앱.

## 2. 배경과 문제
- 상비약이 필요할 때 약국 위치, 영업 여부, 주차 가능 여부를 여러 앱에서 따로 확인해야 한다.
- 약국 영업시간은 실제와 다른 경우가 많아 헛걸음이 생긴다.
- 약국별 일반의약품 가격은 공개 데이터가 없어 비교가 어렵다.
- 대형·할인 약국이 늘고 있으나 한눈에 구분하기 어렵다.

## 3. 목표와 비목표

### 목표
1. 위치 기반으로 영업 중인 약국을 3탭 이내에 찾아 전화 또는 길 안내까지 연결한다.
2. 부정확한 영업시간을 **전화 확인 유도 + 사용자 제보**로 보완한다.
3. 약국 근처 주차장의 무료시간과 예상 요금을 보여 준다.
4. 단계적으로 약 정보(이미지·효능)와 약국별 가격 비교로 확장한다.

### 비목표 (하지 않는 것)
- 의약품 판매, 주문, 배달 중개
- 복약 권유, 진단, 처방성 안내
- 약국 유료 노출 및 광고, 순위 조작
- 자체 길 안내 엔진 개발 (지도 앱 연결로 대체)
- 전문의약품 정보 제공

## 4. 대상 사용자
| 사용자 | 상황 | 핵심 니즈 |
|---|---|---|
| 일반 이용자 | 갑작스러운 두통, 소화불량, 감기 | 가장 가까운 문 연 약국, 전화 |
| 운전 이용자 | 차로 이동 | 주차 가능 여부와 요금 |
| 야간·공휴일 이용자 | 일반 약국이 닫힌 시간 | 심야·공휴일 약국, 편의점 상비약 |
| 보호자 | 아이 또는 노인 약 구매 | 약 안전 정보 (2단계) |

## 5. 범위: 3단계 로드맵

### 1단계 MVP (약국 + 전화 + 주차 + 길안내)
| ID | 기능 | 설명 |
|---|---|---|
| F1 | 내 위치 약국 검색 | 현재 위치 기준 반경 내 약국을 거리순으로 목록과 지도에 표시 |
| F2 | 영업 상태 배지 | 공식 영업시간으로 "영업 중 / 곧 종료 / 종료 / 정보 없음" 추정 표시 |
| F3 | 전화 버튼 | `tel:` 링크로 즉시 통화. "실제와 다를 수 있으니 전화로 확인" 문구 상시 노출 |
| F4 | 필터 | 지금 영업 중, 야간, 공휴일, 대형·할인 약국 |
| F5 | 약국 상세 | 이름, 주소, 전화, 요일별 영업시간, 거리 |
| F6 | 근처 주차장 | 약국 반경 300m 이내 주차장: 거리, 주차면수, 무료시간, 기본·추가 요금, 일 최대요금 |
| F7 | 예상 주차요금 계산 | 30분, 1시간, 2시간, 직접 입력 시간별 예상 요금 (무료시간 이내는 "무료") |
| F8 | 출발 버튼 | 약국 또는 주차장을 목적지로 카카오맵·네이버지도·티맵 길찾기 연결 |
| F9 | 대형·할인 약국 배지 | 직접 큐레이션한 `tags` 기반 배지와 필터 (기준은 앱에 공개) |
| F10 | 심야·공휴일 약국 모아보기 | 국립중앙의료원 데이터 활용 |
| F11 | 안전상비의약품 편의점 | 약국 휴무 시 대안으로 근처 편의점 표시 |
| F12 | 응급 연계 | 119, 1339, 근처 응급실 안내 버튼 |

### 2단계 (약 정보)
| ID | 기능 | 설명 |
|---|---|---|
| F20 | 약 검색 | 제품명, 성분 검색 (일반의약품 중심) |
| F21 | 약 상세 | 제품 이미지, 효능·효과, 사용법, 주의사항 (식약처 원문, 출처 표기) |
| F22 | 알약 식별 | 모양, 색, 각인 입력으로 검색 |
| F23 | 영업 상태 제보 | "방금 열려 있었어요 / 닫혀 있었어요" + 최종 확인 시각 |

### 3단계 (가격과 커뮤니티)
| ID | 기능 | 설명 |
|---|---|---|
| F30 | 로그인 | 소셜 로그인 (제보자 식별) |
| F31 | 약국별 가격 제보 | 약, 약국, 가격, 확인일, 선택적 영수증·가격표 사진 |
| F32 | 가격 비교 | 약별로 근처 약국의 "최근 확인가"를 정렬해 표시 |
| F33 | 약국 자가 등록 (선택) | 약국 계정으로 가격 직접 입력 |
| F34 | 할인 약국 근거화 | 가격 제보 기반 약국별 가격 지수로 배지 근거 보강 |
| F35 | 가격 알림 | 즐겨찾기 약 가격 변동 알림 |

### 이후 후보
내 약 상자(유통기한 알림), 바코드 스캔, 음성 검색, 가족 프로필(기기 내 저장)

## 6. 사용자 흐름 (1단계)
1. 앱 실행 → 위치 권한 요청 (거부 시 주소 직접 입력)
2. 약국 목록과 지도 표시 (기본 정렬: 거리, "지금 영업 중" 필터 기본 ON 가능)
3. 약국 선택 → 상세 화면
4. **전화 버튼**으로 영업 여부 확인
5. 근처 주차장 목록에서 요금 확인 → **출발 버튼** → 지도 앱 길찾기

## 7. 데이터 소스
| 데이터 | 출처 | 비고 |
|---|---|---|
| 약국 위치·전화·영업시간 | 공공데이터포털: 건강보험심사평가원 약국정보서비스 | 약국 자가 등록 정보로 부정확 가능 |
| 심야·공휴일 약국 | 국립중앙의료원 전국 약국 정보 조회 서비스 | 요일·공휴일 시간 포함 |
| 주차장·요금 | 공공데이터포털: 전국주차장정보표준데이터 | 지자체별 갱신 주기 상이 |
| 편의점 | 카카오 로컬 API (카테고리 검색) | 안전상비의약품 판매 여부는 별도 확인 필요 |
| 지도·길찾기 | 카카오맵 JS SDK, 지도 앱 딥링크 | |
| 약 정보 | 식약처 e약은요, 낱알식별, 제품허가정보 (2단계) | 원문 그대로 표시 |

모든 API 키는 사용자가 직접 발급하고 `.env`에만 저장한다. 저장소에 커밋하지 않는다.

## 8. 데이터 모델 (초안)
```
pharmacies   : id, name, address, lat, lng, phone, hours{mon..sun,holiday}, tags[], source, updated_at
parking_lots : id, name, address, lat, lng, capacity, operating_hours,
               free_minutes, base_minutes, base_fee, extra_unit_minutes, extra_unit_fee,
               daily_max_fee, updated_at
drugs        : id, name, company, image_url, efficacy, usage, caution, category   (2단계)
prices       : id, pharmacy_id, drug_id, price, reported_by, confirmed_at, photo_url   (3단계)
reports      : id, pharmacy_id, type(open|closed), reported_at, user_id   (2~3단계)
```
- 1단계는 DB 없이 **수집 스크립트가 생성한 정적 JSON**으로 시작한다.
- 3단계에서 Supabase(Postgres + 인증 + 스토리지)로 이전한다.

## 9. 기술 구성
- 프론트엔드: React 기반 **PWA** (웹과 모바일 공용)
- 안드로이드: **Capacitor**로 동일 코드를 APK/AAB 패키징
- 데이터 수집: Node 또는 Python 스크립트 (주 1회 갱신), API 키는 서버 측에만 보관
- 지도: 카카오맵
- 배포: Vercel 또는 Netlify
- 3단계: Supabase

## 10. 핵심 로직 규칙
- **영업 상태 추정:** 현재 시각이 해당 요일 시작~종료 사이면 영업 중. 종료 60분 전부터 "곧 종료". 시간 정보가 없으면 "정보 없음". 공휴일은 공휴일 시간을 우선한다.
- **주차 요금 계산:** `free_minutes` 이내는 0원. 이후 `base_minutes`까지 `base_fee`, 초과분은 `extra_unit_minutes`마다 `extra_unit_fee` 가산, `daily_max_fee`로 상한. 주차장 유료/무료 구분(요일별)이 있으면 그것을 따른다.
- **정렬:** 거리, 영업 여부 등 객관 기준만 사용한다. 유료 노출 없음.

## 11. 비기능 요구사항
- 첫 화면 로드 3초 이내 (4G 기준), 목록은 위치 확인 후 2초 이내 표시
- 모바일 우선 UI, 한 손 조작, 큰 전화 버튼
- 접근성: 글자 크기 확대, 고대비 지원 (고령 이용자 고려)
- 위치 정보는 서버에 저장하지 않는다 (기기에서만 사용)
- 오프라인 시 마지막 조회 목록 캐시 표시

## 12. 법적·안전 고지
- 모든 화면 하단에 고지: "표시된 영업시간·가격·요금은 참고 정보이며 실제와 다를 수 있습니다. 방문 전 전화로 확인하세요."
- 약 정보 화면: "의사·약사 상담을 대체하지 않습니다. 복용 전 약사와 상담하세요." (식약처 출처 표기)
- 가격은 "제보 기준 최근 확인가"로 표기하고 "최저가" 등 단정 표현을 쓰지 않는다.
- "대형·할인 약국" 판정 기준을 앱 내에 공개한다.
- 판매·주문 중개 기능이 없음을 명확히 한다. 출시 전 약사법·개인정보 관련 검토를 받는다.

## 13. 성공 지표 (MVP 기준)
- 약국 상세에서 **전화 또는 출발 버튼 클릭률**
- "지금 영업 중" 필터 사용률
- 주간 재방문율
- 영업 상태 제보 건수 (2단계 이후)
- 사용자 피드백의 "헛걸음" 신고 비율 (낮을수록 좋음)
